# Extension notebooks

Use these notebooks when you need to reuse a construction pattern or understand
the IR produced by an operator. Each example starts with the clause contract,
builds a small operator, and inspects its behavior.

- [Custom iterators](custom_iterators.ipynb) select static site tuples.
- [Custom predicates](custom_predicates.ipynb) express reusable selection rules.
- [Reading the IR](reading_symbolic_ir.ipynb) helps trace a definition through the compiler.
- [Conditional emissions](conditional_emissions.ipynb) implement piecewise transitions.
- [Custom emissions](extending_emission_clauses.ipynb) combine branch conditions, updates, and tags.
