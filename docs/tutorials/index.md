# Tutorials

These notebooks build a Hamiltonian, compile it, and use it in a small
variational optimisation. They compare the symbolic definition with a native
NetKet operator so you can check the conventions as well as the results.

If you want to customize or extend the DSL itself, see [Advanced Tutorials](../advanced_tutorials/index.md).

- [Ising model](ising_end_to_end.ipynb): diagonal interactions and single-spin flips.
- [Heisenberg model](heisenberg_end_to_end.ipynb): exchange terms and a fixed-magnetisation sector.
- [J1–J2 model](j1j2_end_to_end.ipynb): two bond families with independent couplings.
